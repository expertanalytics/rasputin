## 6. Proposals for Ola

At most three, each touching a governed file, so each goes through the
pipeline by day.

- **N1. `tools/count_loc.py`, the one counter for `CLAUDE.md` §2.** Takes a
  range, prints added, removed and net production lines per file by the §2
  rule. Briefs and `reviewer.md` point at it instead of the rule's text.
  Evidence: lesson 3. Source: Anthropic, *Writing effective tools for
  agents* ("Tools can consolidate functionality, handling potentially
  multiple discrete operations … under the hood", read 2026-10-05). Cost:
  about 80 lines and tests (`@developer`, `@tester`); a `tools/` file is
  governed.
- **N2. `tools/scratch_copy.py <rev> <dir>`.** Makes the `git archive` copy,
  copies the built `_core` into it, and prints the one command that runs
  `pytest` against the copy with the editable finder removed; it also
  serves "run the red tests against the code before the change" without
  `git stash`. `tester.md`'s copy recipe (lines 31-34) then shrinks to the
  command. Evidence: lessons 1 and 2, the four stash uses in §3. Same
  source as N1. Cost: about 60 lines and tests, and P9 in the same PR.
- **N3. Scratchpad repositories are ordinary.** In `guard_push.py` and
  `guard_governance.py`, a `.git/config` under the session scratchpad, and a
  push whose resolved URL (`git remote get-url --push`, after any
  `insteadOf`) is a `file://` path under the scratchpad, are not guarded.
  Evidence: four of seven `guard_unattended` refusals, and both reroutes,
  §2. Source: Anthropic, *Making Claude Code more secure and autonomous
  with sandboxing* ("By defining set boundaries within which Claude can
  work freely, they increase security and agency"; approval fatigue, read
  2026-10-05). Cost: about 20 lines and tests; it is a hook change, so it
  needs Ola's yes. Risk: the resolution must be the one git uses, which
  h12 round 3 showed a user-level config can change; h12's
  `GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1` applies here too.

Not proposed: guarding `git stash` (no incident, and N2 removes the reason),
and passing the brief by reference (three hand retypings in two nights,
about 20 s each; the evening's P4 comes first).
