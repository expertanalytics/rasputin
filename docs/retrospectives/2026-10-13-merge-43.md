## 7. Proposals (Ola decides; defaults in brackets)

- **P1. Dispatch before a prompt** [yes]. In `CLAUDE.md` §3: "Before a command
  that will prompt Ola (a push, a PR, a governed write), start every step that
  does not wait on it, and run the command on its own." About +30 words.
  Evidence: `A:52080` (65 min), `B:98` (96 min). Source: Anthropic,
  *Building effective agents*
  (https://www.anthropic.com/engineering/building-effective-agents), on
  parallel workflows: "Sectioning: Breaking a task into independent subtasks
  run in parallel."
- **P2. Build last retrospective's P5 now** [yes]: `guard_push.py` passes a
  `gh api graphql` query that is not a `mutation`. About 5 lines and tests,
  governed. Today it cost 96 min with no agent running.
- **P3. One brief line for long runs** [yes]. Replace
  `.claude/briefs/common.md@3fe711f1:12`'s first clause with: "Run the full
  Python suite in the background (it takes over 10 minutes) and wait on its
  log with a blocking `tail -F <log> | grep -m1 EXIT`, never `sleep`; change
  nothing in the tree (no stash, checkout or edit) while it runs." About +35
  words, governed. Fixes lessons 2 and 3 and the `Monitor` mismatch. The
  alternative, `Monitor` in the six `tools:` lines, needs a check that
  subagents can use it.
- **P4. Open PRs in the recap** [yes]. `tools/session_state.py` lists every

  and not enqueued, from one `gh pr list` call. About 20 lines and tests,
  governed; costs a network call at session start. Evidence: #208, #198, and
  the 2026-10-07 idea never put to Ola.
- **P5. A test that passes at red gets a mutant** [yes]. In
  `.claude/agents/tester.md`: "Name in the red commit each test that passes at
  red; the kill record covers each with a mutant that removes what it
  guards." About +30 words. Evidence: `589ff1c5`, `1f625345`.
- **P6. The docstring checker judges added lines everywhere** [yes]:
  `check_code_history.py --base <ref>` checks the added lines of the diff in
