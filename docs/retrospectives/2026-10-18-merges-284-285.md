The cause is a gap between two rules. `docs/increments/README.md` puts
`@perf`'s acceptance run after the code review, so its evidence commit always

earlier evidence. Dated, so `docs/benchmarks/quick/` and the stored
quarter outline, which `tools/bench_quick.py` and `tools/bench.py` read, stay
code. Cost: about 5 lines in `tools/push_grant.py` and two tests (one
