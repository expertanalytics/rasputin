## 3. Proposal

1. **A Stop hook that refuses an idle stop while away.** In unattended
   mode the main session's `Stop` is blocked once, with the reason: "Away:
   end the turn only with an agent or background task running. Record a
   question as ASK OLA and start the QUEUE fallback." Claude Code's Stop
   hooks can block with `decision: "block"` and a reason, and receive the
   turn's `last_assistant_message` (code.claude.com/docs/en/hooks, read
   today); a guard against blocking twice (`stop_hook_active`) is from
   memory, unchecked. Evidence: the 1 h 45 min above, and the night idle
   periods in `2026-10-19-night-and-merge-295.md`. Cost: about 20 lines in
   `guard_unattended.py`, three tests, one `Stop` entry in
   `.claude/settings.json` (Ola's edit); one extra model turn per stop while
   away. It makes the one-line rule on fallbacks enforceable rather than
   adding text.

## 4. Lessons

1. A retrospective branch goes through `@reviewer` before its first push;
   Ola's push yes does not drop the step. Two missed today (#297, #300).
2. A merge updates its ROADMAP row (`docs/increments/README.md`); #301 and
   private #15 did not, and the private table stops at 61.
3. A brief that sets a model parameter names its source before it is
   sent; the 75 brief asked for a fit Ola's standing rule forbids.
