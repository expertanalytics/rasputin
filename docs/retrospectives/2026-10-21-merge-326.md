## 3. Lessons, recorded

1. **An agent stops every background command it started before handing
   back** (main session, from finding 3). Ola, 16:32:28: "Great, I like that.
   Keep on keeping on." The developer's loops were the likely reason it stayed
   listed as running for 6 h. Wait for the run's own end notice; never poll
   with `pgrep -f` on a pattern your own wait line contains.
2. **Check a station's series dates against the period before planning runs
   on it** (`@perf`).
3. **Check the forcing grid's extent before searching for stations**: most
   gauges near Bygdin lay outside it (`@perf`).
4. **A brief asking for the full test suite names a venv with the product
   dependencies** (`@developer`). The harness worktree's venv lacked pydantic,
   so 286 product modules did not collect. Finding 6 is the cause.
5. **py-spy needs root on macOS** to read native frames; the fallback,
   cProfile plus macOS's `sample`, took about 10 min (`@perf`).
6. **A red step that adds a command or module greps the tests for the lists it
   joins** (fit sets, the import-layer table) and updates them (finding 1;
   mine, from `a4b530c5`).
7. **`lead_time.py` missed the same day's merges**: `git log
   --since=2026-10-21` means that date at the current time of day, and the
   script read the local `master`, which here was a day stale. Fixed in this
   commit: it reads `origin/master` from midnight.
