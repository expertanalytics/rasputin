## 2. Lessons handed back, recorded

   create` only with the `--title` value in single quotes
   (`tools/push_grant.py`, `unexpandable`, lines 107-127). Three opens were

   #326 (17:20:13, line 20105), the harness change (17:37:33, line 20368),
   the evidence branch (20:09:35, line 22175). The refusal (`NOT_BARE`, line
   56) says "the grant takes only one bare command, every word written out

   memory and the `h20` design. The PR for #38 used single quotes and
   passed (20:09:51). Proposal 1.

   comes from site-packages, not an editable install) or 1 (cmake cannot find
   `rasputin_DIR`). Testers set the worktree up by hand with
   `-Drasputin_DIR=.venv/lib/python3.14/site-packages/tin_engine/share/cmake/rasputin`.
   (As reported in a handback; not rerun here.) Proposal 2.
3. **Fused multiply-add.** Clang's default contraction changed 20,127 of
   55,000 triangles (37 %) against NumPy (`86-evaporation-speed.md`, 2.1);
   the fix is `-ffp-contract=off` on `bindings/evaporation.cpp` alone
   (line 27 of the private repository's `CMakeLists.txt` at `d7fbe4a9`). A bitwise reference must be compiled
   into the same binary as the code it checks, with the same flags. Linux CI
   cannot see a broken rule: there the test tolerance is 1e-12 (design 6.2).
   (Unchecked, from memory: GCC also contracts by default, but only where the
   target has an FMA instruction, which baseline x86-64 lacks; so "Linux GCC
   does not fuse" holds for CI's build, not in general.)
4. **No `pytest-xdist` in the lsm venv**; the suite takes 7.5 min serially
   there (`private/master`'s `pyproject.toml` names no xdist).
