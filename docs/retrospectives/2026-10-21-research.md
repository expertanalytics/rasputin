### 3.2 What others do

**Anthropic, *Effective harnesses for long-running agents*** (26 November
2025, read for this round): an initializer writes a JSON feature list, every
entry with a `passes` field that starts false; each later session reads it
and the progress file and must "choose the highest-priority feature that's
not yet done". The list is what stops an agent that would otherwise "declare
the job done" after some progress. The article does not treat running out of
work as such; the analogy is to 10-20's early "nothing left" call.

### 3.3 Proposals

- **P2, build h24 item 8, with two additions.** Item 8 (designed, about 25

**Claude Code's Bash sandbox** (`code.claude.com/docs/en/sandboxing`, read
for this round): the operating system (Seatbelt on macOS) enforces
`sandbox.filesystem.denyWrite` on every shell command "including their child
processes", whatever the command's text. It already denies writes to
`.claude/settings*`, `.claude/hooks`, `.claude/agents`, `.claude/skills` and
`.git/hooks` and `.git/config` in the working directory, with no exemption.
Edit and Write run outside it and keep their permission rules and hooks.
`allowUnsandboxedCommands: false` removes the retry outside the sandbox.

**P5, a day-time trial of the sandbox for writes.** Settings (Ola's edit):
`sandbox.enabled`, `denyWrite` for the four rule files, the governed tools
and `.git/harness`, `allowUnsandboxedCommands: false`. If it holds,
`guard_governance.py` keeps its Edit and Write arm (the ask is the
authorship record) and drops its Bash arm and the text rule, which is where
every false positive above comes from; `guard_push.py`, and so
`shell_scan.py`, stay, because the sandbox cannot tell a push from a fetch.
Unchecked, and the trial's questions: whether the default protections reach
the same paths inside `.claude/worktrees/<name>/` (below the working
directory), whether cmake, uv, `caffeinate` and `pmset` run under Seatbelt,
and which hosts the network layer must allow. Cost: one settings change and
an hour's trial by day; if it holds, about −120 lines of hook and −6
`REQUIRED-READING.md` sentences on what the guard reads (about −120 words).
