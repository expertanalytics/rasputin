## 4. Lessons from the personas today, with their fixes

- **Check a new module's name against `sys.stdlib_module_names`** before
  naming a file under `tools/` or on any import path. The check exists
  (`tests/python/test_guard_import_shadowing.py:113`) but reads the running
  Python's list, and `pipes` left that list in 3.13, so it passed locally and
  failed only on CI's 3.12. Fix as a tool change: the test also checks the
  modules removed in 3.13 (PEP 594), so it fails on every version.
- **A red step that adds a model field runs `test_catalogue_data.py` and
  `test_layering.py`** as well as its own file (persona's lesson, not
  re-checked here).
- **A shortcut on invalid geometry is tested against the whole repair**, with
  self-crossings outside the box, not only inside it.
- **A polling `pgrep -f <pattern>` matches its own shell**, so the loop never
  ends. Use `pgrep -f '[p]attern'` or wait on a recorded PID.
- **Partial suites run with `--no-cov`**, or the coverage floor fails them.
