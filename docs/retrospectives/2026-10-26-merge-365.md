## 5. Lessons, with their fixes

- **A digest pins only what is exact on every platform.** Floats from libm,
  PROJ or a NumPy transcendental are compared within a stated tolerance.
- **Merge a base branch into a stacked branch only after the base has
  merged**, or the merge carries the base's unfixed state (§1, #365).
- **Split the wait in each post-merge check**: base, suites, Ola, CI, queue.
