1. **Heartbeat reads away state and open prompts.** `work_pipes.py show`,
   which the heartbeat already runs, would print "away mode: off" and every
   open prompt with its age, from the state `away.py` reads. This catches a
   subagent's prompt (finding 2, first case) at the next heartbeat.
   Cost: about 10 lines plus a test.
2. **No prompting act while Ola is believed away and away mode is off.**
   The main session would write the push as an `ASK OLA:` line and not
   issue it, the way a refused act waits. It would also brief no subagent
   to write a protected file. This avoids the main session's own blocked
   turn (second case), which no in-session heartbeat can see. Cost: one
   clause in REQUIRED-READING's *Unattended mode*, paid for by the cut
   below.
3. **Outside watcher (unchecked cost).** A `launchd` job that reads the same
   prompt state and alerts Ola's phone after 15 min. This is the only
